# 沈阳·大连 30万内老破小「收租」筛选智能体

> 纯 Python 标准库，**零依赖**。双击即跑，一键生成**可视化扫房报告**。

## 怎么用（傻瓜式三步）

1. 确保电脑装有 Python 3（装好后到系统「命令提示符」输入 `python --version` 能看到版本即可）。
2. **双击 `run.bat`**（Windows）。它会自动取数 → 打分 → 生成报告。
3. 报告弹窗/打开 `output\rental-report.html`，用浏览器看即可。

也可以手动运行：
```bat
python main.py            :: 完整流程（优先联网，失败自动回退）
python main.py --offline  :: 强制离线用内置样本演示
python main.py --open     :: 跑完自动用浏览器打开报告
```

## 报告里能看到什么（傻瓜式可视化）

- **顶部一排大数字**：推荐标的数、最佳租售比、总价门槛——一眼看懂值不值得做。
- **一句"结论"**：直接告诉你优先买哪一套、为什么。
- **条形对比图**：沈阳/大连各重点板块的年租金回报率，带"推荐线4.0%"。
- **房源卡片**：每套一张卡——总价、估算月租、租售比、回本年限、出租易度、综合分，配彩色进度条；绿色=达标、橙色=勉强、红色=不推荐。
- **全量明细表**：所有房源排序，含净回报与状态。
- **风险标注**：高空置板块/超预算一目了然。

## 数据从哪来

- `crawlers.py` 里有 **贝壳/链家、安居客、58同城** 三个采集入口的框架。因三平台反爬较强且需遵守其条款，默认"尽力联网、失败安全回退"。
- 联网取不到时自动使用 `demo_data.py` 的**内置行情样本**（取自已标注的 2026 年沈阳/大连 30 万内老破小真实行情区间），保证报告永远能生成，并在报告底部明确标注数据来源。
- 想接入真实数据：往 `crawlers.py` 的 `collect_*` 里补合规的解析逻辑即可，字段格式与 `demo_data.py` 保持一致。

## 想调整口味？改 `config.py` 一行即可

| 配置 | 含义 | 默认 |
|---|---|---|
| `BUDGET_WAN` | 总价硬上限(万) | 30 |
| `NET_YIELD_FLOOR` | 净回报门槛(%) | 3.5 |
| `RENT_EASE_FLOOR` | 出租易度门槛 | 60 |
| `TOP_N` | 每城候选条数 | 6 |
| `WEIGHTS` | 出租易度各维度权重 | 交通25/需求25/房龄20/供需15/学区10/季节5 |

> 免责声明：本工具仅作个人投资研究参考。租售比、净回报为行情口径估算，未含空置/维修/税费等全部成本，不构成投资建议；实地购房前请自行核实。

## 文件结构

```
runner/
├── main.py        # 主入口（一键运行）
├── config.py      # 配置（预算/阈值/权重）
├── crawlers.py    # 三平台采集框架 + 失败回退
├── demo_data.py   # 内置行情样本（板块画像 + 房源）
├── score.py       # 打分引擎
├── report.py      # 可视化HTML报告生成
├── run.bat        # 双击启动
└── output/
    └── rental-report.html   # 生成的可视化报告
```
