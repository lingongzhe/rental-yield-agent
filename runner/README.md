# 沈阳·大连 30万内老破小「收租」筛选智能体

> 纯 Python 标准库 + 贝壳官方开放平台数据。数据真实合规、可手动随时更新。

## 数据源（唯一）：贝壳官方 API

- 经**贝壳官方开放平台**（`building.ke.com`/`beike` CLI + 你在本机保存的 API Key）获取**真实挂牌数据**：
  - 二手房在售：总价、面积、房型、楼龄、商圈/小区（`buy search` + `buy detail`）
  - 租房在租：板块、出租面积、月租金（`rent search` 聚合板块中位租金率）
  - 顺带拿到官方**小区租售比 / 小区租房均价**，作为租售比指标的直接依据
- 官方渠道合规、无页面反爬、无派发争议；不估算、不编造。Key 只保存在本机 `~/.beike/`，不会上传。

## 怎么用

```bat
:: 手动更新数据（联网，走贝壳 API，几分钟）
python main.py --refresh

:: 平时出报告（读上次贝壳快照，离线秒出）
python main.py
```

或双击 `run.bat`（A=联网更新，B=快照重建）。Windows 计划任务用 `daily.bat`。

首次使用前需在本机装好贝壳 CLI 并配置 Key：
```bash
curl -fsSL https://raw.githubusercontent.com/LianjiaTech/beike-ai-platform/master/cli/releases/install.sh | bash
beike doctor          # 确认 CLI + Key 可用
```

## 报告里能看到什么

- **顶部 KPI**：推荐标的数、最佳租售比、总价门槛。
- **结论**：优先级建议与依据。
- **板块对比图**：沈阳/大连重点板块年租金回报率，带推荐线。
- **房源卡片**：总价、参考月租、租售比、回本年限、出租易度、综合分；绿=达标/橙=勉强/红=不推荐。
- **全量明细表** 与 **风险标注**（超预算、数据待核实）。
- **数据来源区**：本次使用的快照日期 + 每条数据口径（小区挂牌均价 / 板块租金率中位数 / N条挂牌支撑）。

## 指标口径（分析依据）

| 指标 | 口径 |
|---|---|
| 租售比(年) | `参考月租×12 ÷ 总价`。参考月租优先取该套所在**小区官方租房均价×面积**，缺失时取**同板块挂牌租金率中位数×面积** |
| 回本年限 | `总价 ÷ 年租金` |
| 净回报率 | 与租售比同口径（真实空置/税费未知，**不虚构扣减**，需实地核验，报告已有披露） |
| 出租易度 | 真实维度加权：楼龄 + 板块租金率反推需求强度（缺项不给分、权重重归一化），报告标注"数据待核实" |
| 综合分 | `0.6×租售比分 + 0.4×出租易度分` |

## 配置（config.py）

| 配置 | 含义 | 默认 |
|---|---|---|
| `BUDGET_WAN` | 总价硬上限(万) | 30 |
| `NET_YIELD_FLOOR` | 净回报门槛(%) | 3.5 |
| `RENT_EASE_FLOOR` | 出租易度门槛 | 60 |
| `TOP_N` | 每城候选条数 | 6 |
| `CITY_DISTRICTS`(beike.py) | 逐区检索的城区清单 | 沈阳8个/大连6个 |

## 文件结构

```
runner/
├── main.py        # 主入口：--refresh 联网更新 / 默认快照重建
├── beike.py       # 贝壳官方 API 取数 + 卡片解析 + 快照读写（主数据源）
├── housecli.py    # 可选多平台补充源（贝壳/安居客/58/诸葛/自如；贝壳停机时自足兜底）
├── score.py       # 打分引擎（租售比/回本/净回报/出租易度/综合分）
├── report.py      # 可视化 HTML 报告生成
├── config.py      # 配置
├── run.bat        # 双击运行（A=联网更新，B=快照重建）
├── daily.bat      # 计划任务每日运行（走 --refresh）
└── output/
    ├── beike_data.json    # 贝壳快照（真实数据缓存，可提交供 CI/预览重建）
    └── rental-report.html # 生成的可视化报告
```
